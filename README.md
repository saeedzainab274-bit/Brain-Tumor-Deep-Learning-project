# Brain-Tumor-Deep-Learning-project
# Brain Tumor Classification using Deep Learning

## Objective
To classify MRI brain images into tumor and non-tumor categories using deep learning models.

## Dataset
Brain MRI images containing:
- Tumor Images
- Non-Tumor Images

## Models Implemented
- 3-Layer CNN
- 4-Layer CNN
- 5-Layer CNN
- MobileNetV2
- ResNet50
- DenseNet121

## Best Model
3-Layer CNN

Validation Accuracy: 90%

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Explainable AI (XAI)
Grad-CAM was applied on:
- Best Custom CNN
- MobileNetV2

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Conclusion
The 3-Layer CNN achieved the best performance for brain tumor classification on the given dataset. Grad-CAM was used to visualize the important image regions responsible for predictions.
